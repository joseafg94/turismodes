# SafeRoute

## Ejecutar en local

1. Instala Node.js 22 o superior.
2. Copia `.env.example` a `.env.local` y completa las variables de Supabase y PostHog.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev` y abre `http://localhost:3000`.

El estilo gratuito de OpenFreeMap ya está configurado en la variable `NEXT_PUBLIC_MAP_STYLE_URL`.
